# Aadi Gautam Sharma — Data Science Portfolio

Modern professional portfolio website built with Next.js App Router, TypeScript, and Tailwind CSS.

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide React icons

## Project Structure

```
.
├── app/
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx
├── components/
│   └── portfolio-data.ts
├── public/
├── next.config.mjs
├── tailwind.config.ts
├── tsconfig.json
└── package.json
```

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
