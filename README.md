# Aadi Gautam Sharma — Data Science Portfolio

Minimal modern data science portfolio built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Live Demo
- Coming soon: `https://your-vercel-url.vercel.app`

## Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide React

## Local Development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
